\section{Explicit finite data for the complete \texorpdfstring{$c=4$}{c=4} slice}\label{sec:c4-data}
This section prints a compressed, complete finite certificate for
Theorem~\ref{thm:c4full}.  A reader can reconstruct every row by decoding an offset
word, applying the corrected lift, sorting the three absolute values, and then decoding
the mode and sign strings.

\subsection{Two master words and the boundary rules}\label{sec:c4-support-data}
The zero-sum offset vectors occurring in the periodic rules are encoded as follows.
\emph{This alphabet is local to this subsection.} It differs from the alphabets of
Sections~\ref{sec:offset-data} and~\ref{sec:c4-small-data}; for example the symbol \texttt{6}
denotes \((1,-2,1)\) here, but \((0,1,-1)\) in Section~\ref{sec:offset-data} and
\((-1,2,-1)\) in Section~\ref{sec:c4-small-data}.

Put $n=4m$ and $\kappa=n/2$.  In the two bulk zones use
\[
\begin{aligned}
\delta(j)&=P_1[(j-\psi_1)\bmod16]&& (21\le j\le\kappa-21),\\
\delta(j)&=P_2[(j-\psi_2)\bmod16]&& (\kappa+21\le j\le n-21).
\end{aligned}
\]
Equivalently, define the $48$-letter words by
$W_{\rho,i}[p]=P_i[(p+\phi_i-\psi_i)\bmod16]$ for $0\le p<48$.
Then $W_{\rho,i}[(j-\phi_i-16s)\bmod48]=P_i[(j-\psi_i)\bmod16]$.
Thus the $48$-position description is a refinement of the support rule, not its least period.
It is still needed for the sign tables: positions with the same offset letter may receive
different signs and must not be merged.

\subsection{The 192 balance patterns}\label{sec:c4-balance-data}
The complete $192=4\cdot12\cdot4$ mode-and-sign rows are collected in
Appendix~\ref{sec:c4-balance-data-appendix}.  The main proof uses only the finite-state
specification and the polynomial-in-$Q$ identity verified by those rows; the full hexadecimal
strings are placed in the appendix to keep the main text readable.
\subsection{The six bounded constructions}\label{sec:c4-small-data}
For $m\in\{5,7,11,13,17,19\}$ the following compact data reconstruct every signed entry.
For each such $m$, they produce four groups of $m$ rows, hence four $m\times3$ arrays.
The radius-two offset alphabet below coincides with the one in Section~\ref{sec:small-data}
but differs from the alphabet of Section~\ref{sec:c4-support-data}, where the symbol \texttt{6}
denotes \((1,-2,1)\) rather than \((-1,2,-1)\).

Let $T_j=(a_j,b_j,c_j)$, $a_j<b_j<c_j=a_j+b_j$, be the sorted triple
obtained from the word. In a fixed group $r\in\{0,\ldots,3\}$, write
$T_{4t+r+1}=(a_t,b_t,c_t)$ for $t=0,\ldots,m-1$.
For mode $c,a,b$, respectively, put
\[
(\mu_t,\nu_t)=(c_t,b_t-a_t),\quad(a_t,b_t+c_t),\quad(b_t,a_t+c_t).
\]
Expand each hexadecimal digit of $E,H$ into four binary digits, retaining leading zeroes.
Keep exactly the first $m$ bits in the above row order and read $1$ as $+1$ and $0$ as $-1$
to obtain $\varepsilon_t,\eta_t$. Set
\begin{equation}\label{eq:c4-small-row}
R_{r,t}=\left((\varepsilon_t\mu_t+\eta_t\nu_t)/2,
(\varepsilon_t\mu_t-\eta_t\nu_t)/2,-\varepsilon_t\mu_t\right).
\end{equation}
The switch column lists the nondefault modes; ``--'' means all modes are $c$.
Each reconstructed row has sum zero. The two signed identities in
Lemma~\ref{lem:exact} give zero column sums.
