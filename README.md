# Reproducibility package for the width-three Heffter array sets

This repository accompanies the manuscript
`Existence of integer Heffter array sets IHS(m,3;3) and IHS(m,3;4)`.
It contains only the reproducibility material for the complete fixed slices
`c=3` and `c=4`.

## Contents

- `paper/`: the standalone LaTeX source, the c=3 certificate files, the c=4 support/seed
  certificate, and the appendix containing the 192 c=4 balance patterns;
- `code/`: combined audits of the printed finite constructions and exact symbolic
  balance identities;
- `code/c3/`: the period-24 support and balance rules, JSON certificates, and c=3 verifiers;
- `code/c4/`: the period-16 support rule with a 48-position balance refinement,
  finite seeds, and c=4 verification and regeneration scripts.

The repository intentionally excludes the unfinished `c=5`, `c=7`, width-five experiments,
temporary logs, generated PDFs, and local runtime directories.

## Requirements

Python 3.10 or later is recommended. The two combined audits and the affine support checks
below require only the Python standard library and do not invoke a solver. Solver-backed
certificate generation and regeneration additionally require the packages listed in
`requirements.txt` (`ortools` and `python-sat`).

For optional solver-backed regeneration, install them with:

```text
python -m pip install -r requirements.txt
```

## Verification

### Recommended combined audits

From the repository root, run:

```text
python -B code/verify_c34_printed_finite.py --root paper
python -B code/verify_c34_balance_symbolic.py
```

The finite audit decodes the constructions directly from the printed TeX data and checks
word lengths, integer entries, exact support, zero row and column sums, the bounded
constructions, the finite bridge, and the displayed examples.

The symbolic audit checks the printed data against the stored certificate inputs and sums
the balance packets using exact rational arithmetic. It verifies every coefficient of the
signed balance polynomials, rather than inferring polynomial identities from sampled
values. For c=4, it resolves the absolute-value branches on the tail Q >= 1 and checks all
384 scalar base equations at Q=0 separately.

Finite evaluations alone do not prove the infinite parameter ranges. The manuscript
establishes the required packet structure, branch stabilization, affine endpoints, and
polynomial degree bounds before applying finite verification. All construction data are
printed in the paper: the long 192-row c=4 balance table is in the appendix, and the other
certificate data are in the main text. The code is provided as a computational aid.

### Additional slice-specific checks

From the repository root, run:

```text
python -B code/c3/verify_c3_plus4_transport.py --minimum 67 --maximum 200
python -B code/c3/prove_c3_support_affine.py
python -B code/c3/prove_c3_balance_affine.py
python -B code/c4/prove_c4_support_affine.py
python -B code/c4/verify_c4_all_range.py --maximum 100
python -B code/c4/verify_c4_balance_patterns.py
```

These are deterministic checks of the canonical certificate data. The c=3 transport checker
covers the canonical periodic regime (the displayed command starts at m=67); the six smaller
c=3 preperiod orientations are printed in the manuscript and are covered by the combined
finite audit, but are not regenerated by `generate_c3_all.py`.

### Optional regeneration

The c=4 balance prover can regenerate the 192 affine sign patterns with:

```text
python -B code/c4/prove_c4_balance_affine.py
```

This solver-backed command rewrites `code/c4/c4_balance_affine_patterns.json` and may return
a different valid sign certificate, depending on solver version and search settings. Use a
separate copy if preserving the shipped certificate. In contrast,
`verify_c4_balance_patterns.py` checks the canonical JSON shipped in this repository.

The original solver-backed release was checked with Python 3.12, OR-Tools 9.15.6755, and
python-sat 1.9.dev5. Other compatible versions may also work, but can produce a different
valid solver certificate.

## Paper compilation

Open `paper/IHS_m_3_3_standalone.tex` in a LaTeX environment and compile it with BibTeX in the
usual sequence. The four `\input{...}` files must remain in the same `paper/` directory.
